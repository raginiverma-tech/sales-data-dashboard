## 🌟 Overview

The *Interactive Sales Analytics Dashboard* is a fully responsive, web-based business intelligence tool designed to track, filter, and visualize key sales performance metrics. It empowers stakeholders to monitor revenue trends, regional distribution, and top-performing product categories dynamically through a sleek, dark-themed user interface.

---

## 🚀 Key Features

* *📈 Dynamic Revenue Tracking:* Visualizes monthly revenue trends with precise growth indicators (e.g., MoM comparisons).
* *🔍 Advanced Filtering:* Filter data seamlessly across specific date ranges (e.g., Jan to Oct), regions, and product categories.
* *🍩 Regional Breakdown:* Interactive donut charts highlighting regional revenue contributions with click-to-filter capabilities.
* *📦 Product & Category Insights:* Clear tabular and bar-chart representations tracking top-selling items and category-wise performance.
* *📱 Responsive Design:* Built to provide a smooth analytical experience across modern desktop and mobile viewports.

---

## 🛠️ Tech Stack

* *Markup & Styling:* HTML5, CSS3 (Custom Grid/Flexbox, Dark Theme Styling)
* *Interactivity:* Vanilla JavaScript (DOM manipulation, dynamic filtering)
* *Deployment:* GitHub Pages / Static Hosting
